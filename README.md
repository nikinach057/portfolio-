# Portfolio

Cinematic personal portfolio — React + Vite + TypeScript, React Three Fiber, GSAP, Framer Motion, Lenis, Tailwind.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Content

Edit placeholders in `src/data/content.ts` (and later section data files).

Legacy static site archived in `_legacy/`.
